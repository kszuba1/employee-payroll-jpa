About this app

Lab implementation for Programowanie Sieciowe — Laboratorium V–VIII. Demonstrates Jakarta Persistence 3.2 / Spring Data JPA on a domain of users, salaries and departments, plus Message Oriented Middleware (JMS) for asynchronous salary generation.

Entities

  • User ⟷ Salary — one-to-many (with cascade and orphan removal)
  • User ⟷ Department — many-to-many (join table user_department)

Messaging (Lab VII–VIII)

  • This service hosts the queue server — an embedded ActiveMQ broker on tcp://localhost:61616
  • SalaryConsumerService — a @JmsListener on salary.queue that persists consumed salaries
  • SalaryGenerator runs as a separate app (:salary-generator): it fetches users from this REST API and publishes salaries to the queue over TCP

Tech

  • Kotlin · Spring Boot 4 · Hibernate 7 · H2 in-memory · ActiveMQ / JMS · vanilla JS · multi-module Gradle
